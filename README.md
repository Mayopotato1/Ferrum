# Ferrum

**A fast, lightweight Spotlight-style launcher for Windows, built with Rust.**

Ferrum makes finding and opening things on your PC effortless. Press **Alt + Space** to instantly search applications, launch games, find files and folders, or search the web—all from one clean, minimal interface.

### Features

- **Lightning-fast search** — Responsive fuzzy searching with typo tolerance and a cached index for fast startup.
- **App and game launcher** — Find and launch Windows applications, Steam games, and supported Xbox games.
- **File search** — Quickly find files and folders in common locations.
- **Web search** — Search using your preferred search engine or use `@` shortcuts for specific websites.
- **Customizable** — Adjust transparency, keyboard shortcuts, search engine preferences, and startup behavior.
- **Minimal and lightweight** — Built natively with Rust, with a polished, translucent interface.
- **Open source** — Licensed under MIT.

**Less searching. More doing.**
